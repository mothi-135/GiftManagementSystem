# Epic: Summer Gift Event Management

## Business Scenario

XYZ Private Limited operates across five locations:

* Hyderabad
* Bengaluru
* Chennai
* Pune
* Mumbai

The company plans to conduct a Summer Gift Program for all employees.

The company has:

* 1 Global Admin
* 3 HR Admins
* 5 HR Users
* 400 Employees

HR Admin responsibilities are divided as follows:

* HR Admin 1 → Chennai, Pune
* HR Admin 2 → Bengaluru, Mumbai
* HR Admin 3 → Hyderabad

The event includes:

### Gift Option A

Corporate Merchandise

Employee must select:

* Size
* Color

### Gift Option B

Combo Gift

Contains:

* Suitcase
* Temperature Water Bottle

Employee must select:

Suitcase:

* Size
* Color

Bottle:

* Color

Employees may:

* Select only Merchandise
* Select only Combo Gift
* Select both
* Withdraw enrollment

After enrollment closes, QR codes are generated.

Employees present QR codes during collection.

Issuer validates QR code and issues gifts.

Inventory updates automatically.

Management can monitor enrollment, issuance, inventory, and preference analytics.
